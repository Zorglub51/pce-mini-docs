Tools & Toolchain

The tools used to extract, inspect, and rebuild PCE Mini data files.

mzstool.py

The core tool for working with MZS-encrypted PSB files. Handles the full pipeline: extraction, JSON conversion, rebuilding, and re-encryption.

Requirements

pip3 install zstandard pillow

Commands

CommandDescriptionExample
extract Full extract: .psb.m → JSON + PNG resources mzstool.py extract file.psb.m
build Full build: JSON + PNGs → .psb.m mzstool.py build dir/file.json
unpack MZS decrypt and decompress: .psb.m → .psb mzstool.py unpack file.psb.m
pack MZS compress and encrypt: .psb → .psb.m mzstool.py pack file.psb
psb2json Convert PSB binary to JSON mzstool.py psb2json file.psb
json2psb Convert JSON to PSB binary mzstool.py json2psb file.json

Extract Pipeline

title_mode_top.psb.m | |-- XOR decrypt (key from filename) |-- zstd decompress |-- PSB parse (binary → tree) |-- Export JSON \-- Export resources (textures → PNG) | v title_mode_top/ |- title_mode_top.json |- tex#000.png (if textures present) \- tex#001.png

Build Pipeline

title_mode_top/title_mode_top.json | |-- Load JSON |-- Import resources (PNG → RGBA8) |-- Build PSB binary |-- zstd compress (level 3) \-- XOR encrypt (key from output filename) | v title_mode_top/title_mode_top.psb.m
Output filename determines encryption key The build command derives the output filename from the JSON input path. title_mode_top/title_mode_top.json → title_mode_top.psb.m. The final output basename, including .psb.m, determines the key. An explicit output argument can override the name derived from the JSON; use the exact filename expected by the engine.

build_gamepack.py

High-level tool that generates all four custom PSB files from an XML game list and cover art PNGs.

Usage

python3 tools/build_gamepack.py gamepack.xml -o output_dir/

What it generates

  1. 040/config/title_mode_top.psb.m — Game list
  2. 040/config/title_prof.psb.m — Emulator config
  3. 040/motion/title_jp_titleselect_jp.psb.m — JP covers
  4. 040/motion/title_jp_titleselect_us.psb.m — US covers

Also copies unchanged files (scripts, other configs) from the original alldata extraction.

game_explorer.py

Web-based browser for inspecting PCE Mini game data. Reads directly from .psb.m files and serves an interactive UI at localhost:8080. 

python3 tools/game_explorer/game_explorer.py
# Open http://localhost:8080

Shows both JP and US lineups with cover art, ROM info, and emulator settings.

Workflow

Typical modification workflow 1. Extract original .psb.m $ mzstool.py extract 040/config/title_mode_top.psb.m 2. Edit the JSON (modify game entries, titleNum, etc.) 3. Build back to .psb.m $ mzstool.py build title_mode_top/title_mode_top.json 4. Install in run directory $ cp title_mode_top/title_mode_top.psb.m run/040/config/ 5. Test with m2engage $ cd m2engage-pce-pi5 && ./run.sh
