Building Game Packs

Step-by-step guide to creating a custom game pack for the PCE Mini.

XML Game List Format

The build tool takes a simple XML file describing your game lineup: 

<?xml version="1.0" encoding="UTF-8"?>
<gamepack>
  <name>My Custom Pack</name>

  <!-- JP lineup (PC Engine) -->
  <lineup region="jp">
    <game>
      <name>ゲーム名</name>
      <name_eng>Game Name EN</name_eng>
      <rom>roms/MyGame_J.pce</rom>
      <cover>covers/mygame_jp.png</cover>
      <!-- Optional fields with defaults -->
      <!-- <arch>tg16</arch>         -->
      <!-- <players>1</players>     -->
      <!-- <preamp>0.0</preamp>     -->
    </game>
  </lineup>

  <!-- US lineup (TurboGrafx-16) -->
  <lineup region="us">
    <game>
      <name>US Game Name</name>
      <rom>roms/MyGame_U.pce</rom>
      <cover>covers/mygame_us.png</cover>
    </game>
  </lineup>
</gamepack>

Game Element Fields

FieldRequiredDefaultDescription
nameYes—Display name (JP section uses this)
name_engNo= nameEnglish name (EN section uses this)
romYes—ROM filename
coverYes—Cover PNG path (relative to XML)
archNotg16tg16 | tg16cd | sgx
playersNo11 or 2
preampNo0.0Audio preamp in dB
systemcardNo—super | arcade (CD only)
ccolorNoautoBox color override (0-3)
titlebarNo0Title bar style (0-12)

Auto-Generated Fields

These are computed by the builder — you don't set them in XML:

  • Game ID (regionTag): GAME100, GAME101, ... (JP) / GAME200, GAME201, ... (US)
  • image: Sequential index per lineup (0, 1, 2, ...)
  • csize: Derived from arch + systemcard
  • sor_*: Sort indices computed from game position
  • country: From lineup region

Build Process

build_gamepack.py pipeline gamepack.xml + cover PNGs | |── 1. Parse XML, assign IDs |── 2. Generate title_mode_top JSON (200 items) |── 3. Generate title_prof JSON (root wrapper) |── 4. Pack cover PNGs into sprite sheets |── 5. Generate motion JSONs (frameList + icon maps) |── 6. Build all JSONs to .psb.m via mzstool \── 7. Copy unchanged originals (scripts, other configs) | v output/040/ |- config/title_mode_top.psb.m |- config/title_prof.psb.m |- motion/title_jp_titleselect_jp.psb.m |- motion/title_jp_titleselect_us.psb.m |- config/title_session.psb.m (copied from original) |- script/*.nut.m (copied from original) \- ...

Running the Builder

# Generate placeholder covers for testing
python3 test_pack/gen_covers.py

# Build the game pack
python3 tools/build_gamepack.py test_pack/gamepack.xml -o test_pack/output/

# Install in run directory (backup first!)
cp -r run/040/config run/backup/040_config_backup
cp test_pack/output/040/config/*.psb.m run/040/config/
cp test_pack/output/040/motion/*.psb.m run/040/motion/

# Test
cd m2engage-pce-pi5 && ./run.sh

Testing Strategy

Always test incrementally:

  1. Round-trip test: Extract original → rebuild with zero changes → verify it works
  2. Single file test: Replace only one PSB at a time, keep others original
  3. title_mode_top first: This is the safest to modify (loaded by scripts, good error tolerance)
  4. title_prof last: This crashes m2engage if malformed (native parser, no script fallback)
Diagnostic checklist
  • No SQ output, no sound → title_prof.psb.m is broken
  • SQ output, music, black screen → title_mode_top issue (check sor_* values!)
  • SQ output, visuals, wrong covers → Motion PSB issue
  • Everything works but game doesn't launch → ROM path in title_prof is wrong
