Cover Motion PSBs motion

Sprite sheet textures and animation data for game cover art display in the title selection carousel.

Files

FileLineupOriginal Size
040/motion/title_jp_titleselect_jp.psb.m JP PCE lineup (34 games) 5.3 MB
040/motion/title_jp_titleselect_us.psb.m US TG16 lineup (24 games) 4.1 MB

These are by far the largest PSB files — they contain embedded RGBA texture data for all game cover images.

Sprite Sheet Textures

Cover art images are packed into 1024×1024 RGBA8 sprite sheets. Each game cover is approximately 204×252 pixels (varies slightly).

source.tex#NNN Structure

"source": {
  "tex#000": {
    "icon": {
      "0000": { "attr": 0, "height": 252, "left": 1, "top": 1, "width": 204, "originX": 0, "originY": 0 },
      "0001": { "attr": 0, "height": 252, "left": 206, "top": 1, "width": 204, "originX": 0, "originY": 0 },
      // ... one entry per game cover
    },
    "texture": {
      "height": 1024,
      "pixel": "RGBA8",
      "truncated_height": 1024,
      "truncated_width": 1024,
      "type": "RGBA8",
      "width": 1024
    }
  }
}

Motion / Animation Structure

The "pkg" Parameter

The key mechanism for displaying different game covers is the pkg parameter. Each motion object exposes a pkg variable that the Squirrel scripts set to select which cover to display: 

// In mode_title_select.nut:
m_pkgselect_motion[i].setVariable("pkg", image_index);

front Motion (Main Cover Display)

"front": {
  "layer": [{
    "frameList": [
      { "time": 0, "type": 2, "content": { "icon": "0000", "src": "tex#000" } },
      { "time": 1, "type": 2, "content": { "icon": "0001", "src": "tex#000" } },
      { "time": 2, "type": 2, "content": { "icon": "0002", "src": "tex#000" } },
      // ... one frame per game
      { "time": 50, "type": 0 }  // End marker
    ]
  }],
  "parameter": [{
    "id": "pkg",
    "division": 50,     // Total slots (always 50)
    "rangeEnd": 50      // Range end (matches division)
  }],
  "lastTime": 51        // = max(time) + 1
}

The pkg parameter acts as a timeline index. When set to value N, the motion engine jumps to time=N in the frameList, displaying the icon at that time.

How pkg selects a cover Script: setVariable("pkg", 3) | v front.parameter[0]: id="pkg", division=50 | v Seek to time=3 in frameList | v frameList[3]: icon="0003", src="tex#000" | v source.tex#000.icon["0003"]: left=618, top=1, w=204, h=252 | v Render 204x252 region from sprite sheet

soft32 Composite layer 2 Background/shadow layer
soft33 Composite layer 3 Overlay/border layer

Special Icons

Beyond game covers, sprite sheets may contain special icons for UI elements:

  • Arrow/navigation indicators
  • Selection frame overlays
  • Platform badges

Custom Cover Sprite Sheets

For custom game packs with N games, you need:

  • Cover images resized to a consistent size (e.g., 240×240)
  • Packed into 1024×1024 RGBA8 sprite sheet(s)
  • Icon coordinate map matching the layout
  • frameList with one entry per game (time = game index)
  • division and rangeEnd set to 50 (total slot count)
Simplified covers for custom packs The original covers use complex multi-layer compositions (soft31/32/33) for effects like beveled edges and shadows. Custom packs can use simpler single-layer covers with just the front and thumb motions.
