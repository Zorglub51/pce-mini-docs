title_prof config

Per-game ROM and emulator configuration. Maps each game ID to its ROM file, emulator architecture, country settings, and audio parameters. Also holds global controller, replay, and wallpaper settings.

File Location

040/config/title_prof.psb.m

Original size: ~5,092 bytes (encrypted+compressed). Loaded by m2engage during native C++ init, before any Squirrel scripts run.

Crashes m2engage if malformed Unlike title_mode_top (loaded by scripts with lenient error handling), title_prof is parsed by the native C++ code during early initialization. A malformed file causes an immediate crash with no SQ output and no sound. The native parser is strict about field names — using incorrect names (even for optional-looking fields) will crash.

Top-Level Structure

All data must be wrapped in a root object containing exactly 7 sections:

title_prof.psb structure root |- controller gamepad button mapping & rapid fire config |- game_versions maps GAMEID -> [index, dlc_flag, menu_string] |- m2epi emulator settings (global + per-game) | |- overdrive global CPU speed (int) | |- preamp global audio preamp (float) | |- sram_support global SRAM flag (bool) | \- version per-game configs keyed by GAMEID | \- {GAMEID} {arch, country, rom, preamp, ...} |- player_num single integer (max player slots) |- replay replay recording settings |- title {dev_name: "PceMini"} \- wallpaper {datafile: pattern, max_num: count}
The root wrapper is required The native parser expects exactly this nesting. Omitting root or changing the top-level structure causes a crash.

Loading & Caching

The file is loaded from Squirrel via game_content.nut: 

// game_content.nut, line ~975
function _get_title_prof(_dev_id = 0) {
    local path      = conv_path("config/title_prof.psb", _dev_id);
    local spec_path = conv_path("config/title_prof_specdepend.psb", _dev_id);
    local title_prof      = ::util_load_config(path).root;
    local title_prof_spec = ::util_load_config(spec_path).root;
    title_prof = ::merge_tables(title_prof_spec, title_prof);
    return title_prof;
}

Note: the .root is unwrapped immediately. All subsequent script access uses fields directly (e.g., title_prof.player_num, not title_prof.root.player_num). The result is cached in s_current_title_prof and accessed via get_current_title_prof().

The title_prof_specdepend.psb file is merged on top, allowing platform-specific overrides without modifying the base config.

Per-Game version Entry Fields

FieldTypeRequiredDescription
archstringYes Emulator architecture: "tg16", "tg16cd", "sgx"
countrystringYes Region: "jp" or "us"
romstringYes ROM filename (relative path, e.g., "roms/KungFu_J.pce")

The scripts use a two-level lookup pattern: check global m2epi first, then override with version-specific values if present:

// emulator.nut — helper pattern
function _init_emulator_get_option_by_regionTag(_m2epi, _regionTag, _key, _default) {
    // First check version-specific
    if (_key in _m2epi.version[_regionTag])
        return _m2epi.version[_regionTag][_key];
    // Then check global
    if (_key in _m2epi)
        return _m2epi[_key];
    return _default;
}

game_versions required

Maps each game ID to an internal version index, DLC flag, and menu text string:

"game_versions": {
  "GAME000": [0,  0, "MenuItemText__TITLE_GAME_VERSION_000"],
  "GAME001": [1,  0, "MenuItemText__TITLE_GAME_VERSION_001"],
  "GAME002": [2,  0, "MenuItemText__TITLE_GAME_VERSION_002"],
  "GAME002E": [52, 0, "MenuItemText__TITLE_GAME_VERSION_053"],
  ...
}

Format: [index, dlc_flag, menu_string_key]

ElementTypeDescription
[0] indexintSequential game index. Base games: 0–52. Variant games: 52+.
[1] dlc_flagintAlways 0 for PCE Mini (DLC support unused)
[2] menu_stringstringLocalization string key for version menu
Game variant suffixes
  • GAME002E — "E" suffix = alternate version (e.g., different audio)
  • GAME009S — "S" suffix = special version (e.g., button swap)
  • GAME016F — "F" suffix = hidden bonus game (Force Gear)
  • GAME016T — "T" suffix = hidden bonus game (Twinbee Returns)

Variant IDs must have entries in both game_versions and m2epi.version. The game_versions_layout and game_versions_default fields (optional) control which variants appear in the version selection menu.

Optional game_versions sub-tables

These are checked with "key" in title_prof and can be omitted:

// game_content.nut — version selection
if ("game_versions_layout" in title_prof) {
    // Defines which versions appear in the selection menu per region
    // Format: {regionTag: ["GAME000", "GAME000E", ...]}
}
if ("game_versions_default" in title_prof) {
    // Sets the default version when multiple exist
    // Format: {regionTag: "GAME000"}
}

controller required

Global controller configuration shared across all games:

"controller": {
  "init_emu_key": [1, 2, 2, 1, 0, 0, 0, 0, 1073741824, 0, 512, 1024, 0],
  "init_rapid_speed": 12,
  "key_combo_text": [
    {"combo": 1, "text": "MenuItemText__TITLE_KEY_COMBO_A"},
    {"combo": 2, "text": "MenuItemText__TITLE_KEY_COMBO_B"},
    {"combo": 4, "text": "MenuItemText__TITLE_KEY_COMBO_C"}
  ],
  "rapid_speed_list": [10, 12, 15, 20, 30],
  "use_emu_key": 7
}
FieldTypeDescription
init_emu_keyint[13] Default button mapping. 13-element array mapping logical buttons to physical.
init_rapid_speedint Default rapid fire speed (12 = frames per toggle)
key_combo_textarray Button combo display strings for the settings menu
rapid_speed_listint[] Available rapid fire speed options
use_emu_keyint Bitmask of enabled emulator key features (7 = all basic)

Accessed in title_session.nut:

// title_session.nut
function get_use_emu_key() {
    local controller = ::get_current_title_prof().controller;
    if ("use_emu_key" in controller)
        return controller["use_emu_key"];
    return 0;
}

player_num required

This is a single integer, NOT a dict A common mistake is to make this a per-game mapping. The original value is simply 6. 
"player_num": 6

Represents the maximum number of player slots (not per-game player count — that's in title_mode_top's players field). Accessed directly: 

// title_session.nut
function get_player_num() {
    return ::get_current_title_prof().player_num;  // returns 6
}

replay required — exact field names

Field names must match exactly Using wrong field names (e.g., fps / record_sec instead of the correct names below) will crash the native parser. 
"replay": {
  "init_replay_record_time": 60,
  "max_replay_record_time": 60,
  "replay_record_time_list": [0, 30, 60]
}
FieldTypeDescription
init_replay_record_timeint Default replay recording duration in seconds
max_replay_record_timeint Maximum allowed replay duration in seconds
replay_record_time_listint[] Available options: [0 = off, 30, 60] seconds

Accessed in emulator.nut for the replay recording feature:

// emulator.nut
local title_prof = get_current_title_prof();
if ("max_replay_record_time" in title_prof.replay) {
    record_minutes = title_prof.replay["max_replay_record_time"];
}

title required

Simple object with a single field identifying the device/platform:

"title": {
  "dev_name": "PceMini"
}

dev_name maps to a numeric dev_id via get_title_dev_id(). "PceMini" maps to dev_id 40 (PCE), which determines which 040/ directory to load game data from. 

// title_session.nut
function get_dev_id() {
    return get_title_dev_id(::get_current_title_prof().title.dev_name);
}

wallpaper required — exact field names

Field names must match exactly Using wrong field names (e.g., motion_file / num instead of datafile / max_num) will crash the native parser. 
"wallpaper": {
  "datafile": "motion/bg%02d.psb",
  "max_num": 1
}
FieldTypeDescription
datafilestring Printf pattern for background motion PSB files (relative to 040/)
max_numint Number of available wallpaper variants (1 = just bg00.psb)

Relationships

Internal: game_versions ↔ m2epi.version

Every key in game_versions must also exist in m2epi.version. They share the same GAMEID namespace:

Internal cross-references within title_prof game_versions m2epi.version "GAME000": [0, 0, "..."] <----> "GAME000": {arch, country, rom, preamp} "GAME002": [2, 0, "..."] <----> "GAME002": {arch:"tg16cd", ...} "GAME002E": [52, 0, "..."] <----> "GAME002E": {arch:"tg16cd", ...} Variant IDs (E/S/F/T suffixes) appear in BOTH tables. The original has 83 entries in game_versions across 58 base games.

External: title_mode_top → title_prof

The regionTag field in title_mode_top items links to both game_versions and m2epi.version:

Cross-file linkage via regionTag title_mode_top.psb title_prof.psb items[0]: game_versions: regionTag = "GAME000" ──────────> "GAME000": [0, 0, "MenuItemText..."] name = "THE 功夫" image = 0 m2epi.version: csize = 0 ──────────> "GAME000": { arch: "tg16", country: "jp", rom: "roms/KungFu_J.pce", preamp: 4.08 } items[N]: regionTag = "DUMMY" ──────────> (no entry needed for DUMMY)

Every non-DUMMY regionTag in title_mode_top must have matching entries in both game_versions and m2epi.version. DUMMY entries are ignored and need no title_prof entry.

Advanced Optional Sections

These sections are checked with "key" in title_prof and are safe to omit entirely. They're used by specific games for ROM patching, sound modifications, and bug emulation.

arrange_sound

// Optional: custom audio mixing
"arrange_sound": {
  "volume": 0.7   // Audio volume multiplier (default 0.7)
}

original_bug

// Optional: emulate original hardware bugs
"original_bug": {
  "mode": 1,
  "set_list": [
    {"offset": 1234, "data": [0x00, 0xFF]},
    ...
  ]
}

Applies memory patches at runtime to emulate original hardware quirks.

default_patch

// Optional: apply ROM patches at load time
"default_patch": {
  "mode": 1,
  "set_list": [
    {"offset": 5678, "data": [0x90, 0x90]},
    ...
  ]
}

Patches ROM data at specified offsets before emulation begins.
