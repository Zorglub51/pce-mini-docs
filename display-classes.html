Display Classes

Layer, Motion, and Indicator — the native C++ classes that Squirrel scripts use to build and animate the entire m2engage UI.

1. Overview & Layer Tree

m2engage's UI is built as a tree of Layer objects. Each layer has position, size, opacity, and transform properties. Motion objects attach to layers to drive PSB animations. Indicator objects render text on layers. All three are native C++ classes exposed to the Squirrel VM.

Layer Tree (typical title select screen) Root LayerFolder | |-- ScaledLayerFolder (menu layer folder, priority-based) | | | |-- ScaledLayer m_layer (PRI_BG) | | |-- Motion m_motion_bg (chara="grandmenu", motion="main") | | \-- Motion m_pkgselect_motion[0..4] (cover art carousel) | | | |-- ScaledLayer m_layer_down (PRI_BG_DOWN) | | \-- Motion m_motion_bg_down (motion="main_down") | | | |-- ScaledLayer m_layer_back (PRI_BG_BACK) | | \-- Motion m_motion_bg_back (motion="back") | | | \-- ScaledLayer m_layerText (PRI_TEXT) | |-- Indicator m_caption (font resource, centered) | |-- Indicator m_guide (font resource, centered) | \-- Indicator m_text_Title (game title text) | \-- EmuTask (emulator display, separate from UI layers)

The workflow is always: create layer → register motion resource (PSB) → create Motion on layer → set chara/motion → progress() to render first frame.

3. LayerFit

Extends Layer. Automatically scales content to fit a target dimension while preserving aspect ratio. Used for all full-screen UI layers.

MethodDescription
setFitWidth(width)Scale to fit target width
setFitHeight(height)Scale to fit target height
getFitScale()Returns the computed scale factor
// LayerFit constructor takes a parent layer
local layer = LayerFit(parent_folder);
layer.setFitHeight(720);  // Scale to 720p height

4. LayerFolder

Extends Layer. A container that groups child layers into a hierarchy. Transform operations on a folder cascade to all children (unless independentLayerInherit is set). 

local folder = LayerFolder(parent);  // null for root
local child = Layer(folder);          // parented to folder
folder.setAngleDeg(45);              // rotates all children too

Other native layer types (less commonly used):

ClassDescription
LayerViewView/camera layer for viewport transforms
LayerProxyReference to another layer (no new geometry)
LayerExExtended layer with additional features

5. ScaledLayer & ScaledLayerFolder

Squirrel wrapper classes defined in utils.nut. These are used throughout the UI codebase instead of raw LayerFit/LayerFolder.

ScaledLayer (extends LayerFit)

class ScaledLayer extends LayerFit {
    constructor(owner = null) {
        LayerFit.constructor(owner ? owner : ::util_get_menu_layerFolder());
        LayerFit.setFitHeight(SCREEN_YSIZE);  // auto-fit to 720p
    }

    function registerMotionResource(_motion_psb, _purge_psb = null)
    function clip_coord_by_safe_area(_coord_x, _coord_y, _check_bounds)
}

Default parent is the global menu layer folder. Automatically fits to screen height. registerMotionResource() wraps the native method with optional PS3 memory purge.

ScaledLayerFolder (extends LayerFolder)

class ScaledLayerFolder extends LayerFolder {
    rotate_mode = null;

    constructor(_owner = null, _priority = null)
    function set_rotate_mode(_mode)  // RotateMode.NONE/ROT_L/ROT_R/ROT_180
}

6. Motion (Animation Controller)

The key class for displaying PSB animations. A Motion is attached to a Layer and drives it using data from a registered PSB resource. One layer can have multiple motions (each with different chara/motion combos).

Creation & Setup

// 1. Create layer and register PSB resource
local layer = ScaledLayer();
layer.registerMotionResource(rsc.find("040/motion/title_jp_titleselect_jp.psb.m"));

// 2. Create Motion on the layer
local motion = Motion(layer);

// 3. Set character and animation name (from PSB)
motion.chara = "grandmenu";      // character/animation set
motion.motion = "main";           // animation within the set

// 4. Configure
motion.opacity = 255;
motion.visible = true;
motion.independentLayerInherit = true;

// 5. Render first frame
motion.progress();

Core Properties

PropertyTypeDescription
charastringCharacter/animation set name from PSB
motionstringAnimation name within the character set
visibleboolShow/hide this motion
opacity0–255Transparency
independentLayerInheritboolDon't inherit parent transforms

Motion also inherits all Layer position, transform, color, and clipping properties (x, y, top, left, angle, scale, flipX, smoothing, priority, setColorFilter(), etc.).

Animation Variables

PSB motions define variables that control which frame/state is displayed. This is how the cover art carousel selects which game icon to show.

// Select which cover art to display (variable "pkg" defined in PSB)
motion.setVariable("pkg", game_index);

// Control UI state via variables

7. Indicator (Text Display)

Renders text on a layer using a loaded font resource. Fonts are PSB files loaded via Resource().

Creation

// Load font resource
local font_path = conv_path("system/font/multi_font.psb");
local rsc = Resource();
rsc.load(font_path);
while (rsc.loading) { yield null; }

// Create indicator on a layer
local indicator = Indicator(layer, rsc.find(font_path));
indicator.visible = true;
indicator.setRecognizeTag(true);       // enable tag parsing in text
indicator.fontColor = 0xFFFFFFFF;      // white (ARGB)
indicator.setAlignment(CONSOLE.ALIGNMENT_CENTER);
indicator.print("Hello World");

IndicatorFitMaxWidth (Squirrel wrapper)

Extends Indicator. Auto-scales font to fit within a maximum width. Defined in utils.nut. 

local indicator = IndicatorFitMaxWidth(layer, font_resource, max_width);
indicator.print("Long text that will be auto-scaled to fit");

9. Usage Patterns

Full Layer + Motion Setup

// Load motion PSB resource
local motion_path = conv_path("motion/title_jp_titleselect_jp.psb");
local rsc = Resource();
rsc.load(motion_path);
while (rsc.loading) { yield null; }

// Create layer, register resource
local layer = ScaledLayer();
layer.visible = true;
layer.smoothing = true;
layer.priority = PRI_BG;
layer.registerMotionResource(rsc.find(motion_path));

// Create motion on layer
local motion = Motion(layer);
motion.chara   = "grandmenu";
motion.motion  = "main";
motion.opacity = 255;
motion.visible = true;
motion.independentLayerInherit = true;
motion.progress();  // render first frame

// Control via variables
motion.setVariable("pkg", 3);      // show game #3's cover
motion.setVariable("lineup", 0);   // JP lineup

Text Display

// Layer for text (higher priority = drawn on top)
local textLayer = ScaledLayer();
textLayer.visible = true;
textLayer.smoothing = true;
textLayer.priority = PRI_TEXT;

// Create indicator with font
local indicator = Indicator(textLayer, rsc.find(font_path));
indicator.visible = true;
indicator.setRecognizeTag(true);
indicator.fontColor = 0xFFFFFFFF;
indicator.setAlignment(CONSOLE.ALIGNMENT_CENTER);
indicator.print("R-TYPE");

Fade Animation

// Fade out over 30 frames
motion.animateOpacity(0, 30);

// Scale up over 60 frames
motion.animateScale(2.0, 2.0, 60);

// Rotate 360 degrees over 120 frames
motion.animateAngleDeg(360, 120);

Per-Frame Update Loop

// In a coroutine-based game loop:
while (running) {
    motion.progress();           // advance animation
    handle_input();
    yield null;                  // yield to engine for rendering
}
progress() is essential You must call progress() on each Motion every frame for its animation to advance. Without it, the motion stays frozen on its current frame. The yield null at the end hands control back to the native engine, which actually renders the layer tree to screen.
