PCE Mini Internals

A comprehensive guide to the internal data formats and architecture of the PC Engine / TurboGrafx-16 Mini console, powered by M2's m2engage emulator.

What is this?

The PC Engine Mini (Japan) / TurboGrafx-16 Mini (US) / CoreGrafx Mini (EU) is a miniature retro console released in 2020. It runs an ARM-based SoC with a custom emulator called m2engage, built by M2 (the renowned Japanese developer known for pixel-perfect ports).

This documentation covers the internal file formats used by m2engage to define game lists, emulator settings, cover art animations, and more. The goal is to understand these formats well enough to build custom game packs.

High-Level File Structure

All game data lives under two directories, relative to the m2engage working directory:

m2engage working directory |- system/ Platform-wide resources | |- config/ System config PSBs | |- script/ Squirrel .nut scripts | |- motion/ Shared motion/animation PSBs | \- sound/ Audio assets | |- 040/ Title pack (dev_id=40 = PCE) | |- config/ Game list & emulator config | | |- title_mode_top.psb.m Game list (200 items) | | |- title_prof.psb.m ROM & emulator settings | | |- title_session.psb.m Session/save config | | \- ... | |- motion/ Cover art & animations | | |- title_jp_titleselect_jp.psb.m JP cover sprites | | |- title_jp_titleselect_us.psb.m US cover sprites | | |- bg01.psb.m Background motion | | \- ... | \- script/ Title-specific script overrides | |- version Version file \- shutdown.png Shutdown image
alldata.bin On the original hardware, all files are packed into alldata.bin with an alldata.psb.m manifest. However, m2engage can also read from extracted directories directly — extracted folders take priority over alldata.bin.

The Four Key Files

To create a custom game pack, you need to generate four PSB files. Everything else can be copied from the originals unchanged:

config title_mode_top.psb.m

The master game list. 200 items defining every game slot across JP and US lineups, with sorting indices, display names, and platform metadata.

config title_prof.psb.m

Per-game ROM and emulator configuration: architecture, ROM filename, country, audio preamp, controller mapping, and more.

motion title_jp_titleselect_jp.psb.m

JP lineup cover art. Contains 1024×1024 sprite sheet textures with icon coordinates and animation frame lists.

motion title_jp_titleselect_us.psb.m

US lineup cover art. Same format as JP but for the TurboGrafx-16 game lineup.

Quick Reference

Concept Details
File encryption MZS format: XOR cipher + zstd compression. Key: 8!7ZZnJAr/wfc
Config format PSB (PackageSuB) — M2's proprietary binary format, convertible to/from JSON
Script engine Squirrel VM (statically linked into m2engage)
JP game count 34 games (titleNum)
US game count 24 games (titleNumTG)
Items array size Always 200 (50 per section × 4 sections)
Tool mzstool.py — extract/build pipeline for .psb.m files
