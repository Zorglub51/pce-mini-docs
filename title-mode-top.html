title_mode_top config

The master game list. Defines all 200 game slots across four sections, with metadata, display names, sorting indices, and platform information.

File Location

040/config/title_mode_top.psb.m

Original size: 5,092 bytes (encrypted+compressed). Decodes to ~113 KB JSON.

Top-Level Structure

{
  "items": [ ... ],              // 200 game entries (always 200)
  "motion_basename": "title_grandmenu",
  "motion_chara": "grandmenu",
  "motion_label": "stand",
  "scroll_frame": 10,
  "scroll_variable": "gametitle_normal",
  "titleNum": 34,                // JP game count
  "titleNumTG": 24               // US game count
}
All top-level keys are required The motion_*, scroll_* keys are used by the native engine for menu animation. Omitting them may cause rendering issues.

The 200 Items Array

The items array is always exactly 200 entries, divided into four sections of 50. Unused slots are filled with DUMMY entries.

Item Entry Fields

Each of the 200 items has these fields:

FieldTypeDescriptionExample
regionTagstring Game ID. Links to title_prof entries. "DUMMY" for empty slots "GAME000"
name / tnamestring Display name. name = original, tname = translated/display version "THE 功夫"
imageint Index into the cover motion sprite sheet (0-based) 0
csizeint Platform type (see table below) 0
ccolorint Box/border color in UI (see table below) 0
playersint Number of players (1 or 2). DUMMY entries use 1 1
demo_timeint Demo/attract mode duration in milliseconds 6120
titlebarint Title bar style (0-12) 4
ScreenModeint Display mode (0 = default) 0
EmuOfsX / EmuOfsYint Emulator screen offset in pixels 0
dev_namestring Always "PceMini" "PceMini"
actionstring Always "Boot" "Boot"
regionTagEstring Always "NO" "NO"
regionTagS1 / regionTagS2string Always "NO" "NO"
copy / descstring Unused, always empty "" ""

Sorting Fields

FieldDescription
sor_namePosition when sorted alphabetically by name
sor_datePosition when sorted by release date
sor_demoPosition when sorted by demo mode order
sor_genrPosition when sorted by genre
sor_pnumPosition when sorted by player count
CRITICAL: Sorting indices must be in range! Every sor_* value must be in the range [0, titleNum-1] for JP items (or [0, titleNumTG-1] for US items). Out-of-range values cause black screen — the scripts silently crash with an array out-of-bounds when building the sort index table. This is the #1 gotcha when modifying game lists.

DUMMY Entries

Unused slots (after the real games in each section) must be filled with DUMMY entries. Here's the template from the original data: 

{
  "EmuOfsX": 0,
  "EmuOfsY": 0,
  "ScreenMode": 0,
  "action": "Boot",
  "ccolor": 0,
  "copy": "",
  "csize": 0,
  "demo_time": 6180,
  "desc": "",
  "dev_name": "PceMini",
  "image": <section_index>,
  "name": "DUMMY",
  "players": 1,             // Note: 1, not 0!
  "regionTag": "DUMMY",
  "regionTagE": "NO",
  "regionTagS1": "NO",
  "regionTagS2": "NO",
  "sor_date": <section_index>,
  "sor_demo": <section_index>,
  "sor_genr": <section_index>,
  "sor_name": <section_index>,
  "sor_pnum": <section_index>,
  "titlebar": 0,
  "tname": "DUMMY"
}
DUMMY sor_* values DUMMY entries' sor_* should be set to their position within the 50-item section (0-49). This ensures they never reference an out-of-bounds index regardless of titleNum/titleNumTG values.

Section Mirroring

The EN sections (100-149, 150-199) mirror their JP counterparts (0-49, 50-99) with the same regionTag, image, csize, etc. Only the display name differs:

  • Section 0-49: tname = "THE 功夫" (Japanese)
  • Section 100-149: tname = "The Kung Fu" (English)

The EN variants have players: 0 in some original entries (used to indicate they're display variants, not independent games).

Example: Minimal 5-Game Pack

{
  "items": [
    // [0-4]: 5 JP/PCE games with sor_* in range [0,4]
    { "regionTag": "GAME100", "tname": "Game One",   "image": 0, "csize": 0, "sor_name": 0, "sor_date": 0, ... },
    { "regionTag": "GAME101", "tname": "Game Two",   "image": 1, "csize": 0, "sor_name": 1, "sor_date": 1, ... },
    { "regionTag": "GAME102", "tname": "Game Three", "image": 2, "csize": 0, "sor_name": 2, "sor_date": 2, ... },
    { "regionTag": "GAME103", "tname": "Game Four",  "image": 3, "csize": 0, "sor_name": 3, "sor_date": 3, ... },
    { "regionTag": "GAME104", "tname": "Game Five",  "image": 4, "csize": 0, "sor_name": 4, "sor_date": 4, ... },
    // [5-49]: DUMMY entries with sor_* = section_index
    { "regionTag": "DUMMY", "sor_name": 5, "sor_date": 5, ... },
    { "regionTag": "DUMMY", "sor_name": 6, "sor_date": 6, ... },
    ...
    // [50-54]: 5 US/TG16 games (same pattern)
    // [55-99]: DUMMY
    // [100-104]: EN translations of JP games
    // [105-149]: DUMMY
    // [150-154]: EN translations of US games
    // [155-199]: DUMMY
  ],
  "motion_basename": "title_grandmenu",
  "motion_chara": "grandmenu",
  "motion_label": "stand",
  "scroll_frame": 10,
  "scroll_variable": "gametitle_normal",
  "titleNum": 5,
  "titleNumTG": 5
}
